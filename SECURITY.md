# Segurança

## Dados da demonstração

Os nomes, pedidos, produtos e valores incluídos no projeto são fictícios e servem apenas para demonstração.

## Uso com dados reais

- Não publique informações pessoais ou comerciais confidenciais.
- Remova nomes, documentos, endereços e dados de pagamento.
- Não inclua senhas, tokens ou strings de conexão no código.
- Armazene credenciais em variáveis de ambiente ou gerenciadores de segredos.
